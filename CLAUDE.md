# DiktoMed — принципы проекта

Ārstu diktāti → medicīniskā dokumentācija. Работает на сервере больницы.
`web/` — Next.js 14 + Prisma + Postgres, `worker/` — Python (faster-whisper).

## Обязательные правила

1. **Только локально.** Аудио, текст и модели не покидают сервер больницы.
   Никаких облачных API, CDN, внешних шрифтов, телеметрии. Воркер — во
   внутренней сети Docker без выхода наружу.
2. **Утверждает человек.** Пометки и подсказки (в том числе от LLM) никогда не
   меняют текст сами. Утверждение заблокировано, пока открыты пометки HIGH.
3. **Сторона операции и числа не обучаются.** Исправления «labā/kreisā» и любых
   чисел/доз не попадают в выученные исправления (web `isProtectedWord`) и не
   предлагаются воркером (`is_protected_correction`). Есть тесты — не ломать.
4. **Протокол — только из утверждённого текста.** Каждое поле = значение +
   дословные цитаты; цитата обязана быть в тексте, числа и сторона в значении —
   в цитате и совпадать с плановой стороной (`protocol.validate`). Поле с
   предупреждением принимает только человек; утверждение протокола заблокировано,
   пока есть нерешённые поля.
5. **Нет данных пациентов в логах и журнале аудита.** Только id и счётчики.
6. **Метрики описывают модель, а не людей.** Никаких рейтингов сотрудников.
7. **Интерфейс только на латышском.** Код и имена — на английском.
8. **Дизайн — как платформа Shadowy:** токены, `data-slot` + `.ui-new`.
   Шрифт — Poppins (локальные файлы в `web/public/fonts`), таймкоды — JetBrains Mono.

## Схема БД

Таблицы в snake_case (`@@map`/`@map`): воркер пишет в них обычным SQL.
Схема меняется только добавлением; миграции в `web/prisma/migrations`.

## Проверки перед push

```bash
cd web && npm run typecheck && npm run lint && npm test
cd worker && pytest
```
